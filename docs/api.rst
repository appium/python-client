API reference
=============

* :class:`webdriver.Remote <webdriver.webdriver.WebDriver>` creates a driver session.
* :class:`AppiumBy <webdriver.common.appiumby.AppiumBy>` defines locator strategies.
* :class:`WebElement <webdriver.webelement.WebElement>` represents an element on the device.
